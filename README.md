1. The File: schemaorg-current-https.jsonld
   This file is the master machine-readable dictionary of the entire Schema.org vocabulary. It contains every single Category (Type) and Attribute (Property) defined by Schema.org in one massive file.

Because it is written in JSON-LD (JSON for Linked Data), it is structured as a massive graph of interconnected concepts rather than a simple top-down list.
